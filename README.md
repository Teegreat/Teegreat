## 👨‍💻 About Me

I'm a Full Stack Developer who enjoys building products from idea to production. 
My work spans web applications, mobile apps, backend systems, cloud infrastructure, and deployment automation. 
I like solving real business problems with technology and creating products that are reliable, scalable, and enjoyable to use.

### What I Do

### What I Do

- ⚛️ Build modern web applications with React, Next.js, and TypeScript
- 📱 Develop mobile apps using React Native, Expo, and EAS
- 🚀 Design scalable APIs with Node.js, Express, and NestJS
- 🗄️ Work with MongoDB, PostgreSQL, Firebase, and Supabase
- ☁️ Deploy and manage cloud infrastructure on AWS
- ⚙️ Build CI/CD pipelines, automation workflows, and developer tooling
- 🌐 Create WordPress and headless CMS solutions when needed

### Current Focus

* Building products through FastSail Tech
* Improving DevOps and cloud architecture skills
* Creating scalable SaaS and business solutions
* Exploring automation and AI-powered workflows
